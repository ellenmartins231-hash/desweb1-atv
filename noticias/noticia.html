Desenvolvimento Web I

De uma página de perfil a um portal de notícias

A evolução do projeto e a criação de novos conteúdos.

Publicado em: 21 de agosto de 2026 às 21:06

Na primeira aula de Desenvolvimento Web I, criamos uma página de perfil utilizando HTML e CSS. A proposta inicial era apresentar algumas informações pessoais, interesses e experiências.

Com a evolução do projeto, a página passou a fazer parte de um portal de notícias, permitindo a organização de diferentes conteúdos em uma mesma aplicação.

Organização da página

Para estruturar o portal, utilizamos elementos semânticos do HTML, como header, nav, main, section, article e footer.

Esses elementos ajudam a organizar o conteúdo da página de acordo com a função de cada parte. Além disso, tornam a estrutura mais clara e facilitam a manutenção do projeto.

Desenvolvimento do projeto

Durante o desenvolvimento, também foram utilizados recursos do CSS para definir cores, espaçamentos, tamanhos, bordas e posicionamento dos elementos.

O projeto continua sendo desenvolvido ao longo da disciplina, recebendo novos conteúdos e funcionalidades conforme novos conceitos de desenvolvimento web são estudados.
